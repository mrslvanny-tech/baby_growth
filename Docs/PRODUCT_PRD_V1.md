# 小芽成长 V1 产品文档

## 1. 产品定位

小芽成长是一个把宝宝“每一个第一次”养成一棵会长大的小树的 iPhone App。

V1 只跑通核心闭环：

```text
创建宝宝档案 -> 首页成长树 -> 记录成长节点 -> 小树变化 -> 历史回顾 -> 单节点纪念卡分享
```

产品不做医学评估，不做发育诊断，不做社区，不做排行榜，不做复杂喂养/睡眠/排便记录。

## 2. V1 范围

### P0 必做

- Onboarding 创建宝宝档案：昵称、出生日期、默认头像。
- 首页成长树：时间标签、树阶段、记录数量、最近节点、记录入口。
- 时间标签切换：天数、月龄、下个月龄倒计时。
- 节点模板选择：6 类内置模板，支持自定义。
- 记录编辑：标题、日期、描述、分类、照片入口、心情标签。
- 保存反馈：返回首页、Toast、树状态刷新、纪念卡预览。
- 历史记录：倒序列表和详情。
- 单节点纪念卡：预览与系统分享。
- 设置页：编辑宝宝昵称、出生日期、头像。

### V1 不做

- 养料补给/浇水闭环。
- Widget、Watch、灵动岛。
- iCloud、多宝宝、家庭共享。
- 身高体重趣味卡。
- 成长年轮、成长岛、主题商店。
- AI 育儿建议和任何医学判断。

### 原型导入结论

已阅读 Inspire Prototype v1.9 导出包。V1 吸收首页大树、时间标签、独立设置页、模板卡片列表、保存后纪念卡等方向；水滴养料闭环、岛屿地图和身高体重页不进入 V1，实现顺延到 V1.1/V2。

## 3. 用户路径

### 首次启动

1. 用户打开 App。
2. 系统预填昵称“小芽”。
3. 系统预填出生日期为当前日期前 128 天。
4. 用户可切换默认头像、修改昵称和日期。
5. 点击“开始记录成长”进入首页。

### 首页记录

1. 首页展示宝宝时间标签和成长树。
2. 用户点击“记录新成长”。
3. 选择模板或自定义记录。
4. 填写记录并保存。
5. 返回首页，树状态更新，出现“已点亮芽点”提示。
6. 自动展示一次纪念卡预览。

### 历史和分享

1. 用户从首页进入历史记录。
2. 查看单条成长详情。
3. 点击“生成纪念卡”。
4. 使用系统 Share Sheet 分享。

### 设置

1. 用户从首页右上角进入设置。
2. 点击“编辑”。
3. 修改昵称、出生日期、头像。
4. 保存后首页、历史、分享卡文案即时使用新资料。

## 4. 成长树规则

树阶段由记录数量驱动：

| 记录数量 | 阶段 |
| ---: | --- |
| 0 | 种子 |
| 1-3 | 小芽 |
| 4-8 | 幼苗 |
| 9-15 | 小树 |
| 16-25 | 开花树 |
| 26-40 | 结果树 |
| 41+ | 纪念树 |

节点类别映射：

| 类别 | 树元素 |
| --- | --- |
| 大运动 | 小路/脚步 |
| 精细动作 | 叶片 |
| 语言 | 果实/音符 |
| 情绪社交 | 星星/花朵 |
| 生活习惯 | 地面元素/水滴 |
| 纪念日 | 光环/太阳 |
| 自定义 | 星星 |

树状态是记录数据的计算结果，不单独落库。

## 5. 文案原则

- 温柔、克制、有纪念感。
- 不出现“落后、超前、达标、不达标、异常、风险”等医学或焦虑表达。
- 分享卡水印使用“来自「小芽成长」”，不做强广告。

## 6. 核心指标

- 建档完成率。
- 首页到保存记录转化率。
- 首周人均记录数。
- 分享卡生成率。
- 分享成功率。
- D7 留存。

V1 埋点可先以协议和 no-op 实现预留，不阻塞产品上线。

## 7. 验收标准

- 新用户 30 秒内能完成建档并看到首页。
- 用户 60 秒内能完成一次模板记录并看到树变化。
- 保存后的纪念卡只自动展示一次，不因返回、刷新或重进页面重复弹出。
- 修改出生日期后，首页时间、历史详情、分享卡重新计算。
- 小屏 iPhone 不挤压，底部主按钮可点击。
- VoiceOver 可读关键按钮和出生天数。
