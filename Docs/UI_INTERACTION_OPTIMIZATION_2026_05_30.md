# 小芽成长 V1 UI/交互优化需求文档

日期：2026-05-30

目标：进一步贴近 Apple Human Interface Guidelines，减少冗余交互，突出“记录成长瞬间 -> 点亮叶片 -> 小树成长”的核心价值链。

## 1. 首页优化

首页弱化品牌，强化成长内容。

- 顶部标题从“大号产品名”改为居中的弱标题，例如“言言成长记录”。
- 标题使用约 18-20pt、Medium、Secondary Label、60% opacity。
- 删除下方“查看历史记录”卡片。
- 保留左上角时光轴按钮进入成长记录列表。
- 首页视觉重心集中在宝宝时间、小树、已点亮数量和“记录新成长”按钮。

## 2. 小树素材

当前 36 阶段树图已接入 Asset Catalog，并使用统一透明画布。

后续素材升级方向：

- 推荐重新生成 36 阶段成长树，1024x1024 或更高分辨率，透明 PNG。
- 每张保持树根位置、树冠中心、画布尺寸一致。
- Asset Catalog 后续补齐 1x/2x/3x，避免真机放大造成模糊。

## 3. 成长记录编辑页

编辑页只保留完成一次记录真正需要的字段。

- 分类选择器不再展示“自定义”。
- 保留大运动、精细动作、语言、情绪社交、生活习惯、纪念日。
- “取消”放在导航栏右侧，返回按钮由系统保留在左侧。
- 删除心情模块。
- 保存时不再写入心情标签。

## 4. 日期组件

产品内日期选择统一使用 iOS Wheel DatePicker。

应用范围：

- 新建成长记录的发生日期。
- 宝宝信息页的出生日期。
- 新手引导页的出生日期。

目标：

- 符合国内用户对年月日滚轮选择的习惯。
- 降低日期选择学习成本。
- 统一全产品日期交互。

## 5. 新手引导页

新手页聚焦“开始记录”，删除无价值模块。

- 删除顶部树展示。
- 删除换头像交互。
- 页面标题改为“欢迎来到小芽成长”。
- 副标题：“记录每一个第一次，看着小树慢慢长大。”
- 表单只保留宝宝昵称和出生日期。
- 底部保留“开始记录成长”。

## 6. 纪念卡

纪念卡强化树的纪念意义。

- 树区域占比提升。
- 增加柔和背景渐变和轻微阴影。
- 使用与首页一致的成长树状态。
- 导出图片时渲染最终树形，不播放入场动画。

## 7. 统一设计原则

- 减少填写：宝宝昵称、日期、一句话记录即可完成。
- 弱化产品名，强化成长记录。
- 核心反馈只有一个：记录成长 -> 点亮叶片 -> 小树成长。
- 不引入头像、心情、积分、等级等干扰元素。
- 优先使用 Apple 原生控件：Navigation Bar、Form、Sheet、Wheel DatePicker。

## 8. V1 Aha Moment

用户应能在 30 秒内完成：

```text
输入宝宝昵称
-> 选择生日
-> 记录第一个成长瞬间
-> 看到叶片被点亮
-> 生成纪念卡
-> 分享给家人
```
