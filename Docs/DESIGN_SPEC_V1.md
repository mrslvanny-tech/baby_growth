# 小芽成长 V1 设计规范

## 1. 设计原则

- 温柔型记录：不制造任务压力，不做惩罚机制。
- 行为点亮生命：用户记录行为驱动成长树变化。
- Apple 原生感：优先使用系统控件、系统字体、系统动效。
- 克制商业化：分享卡可传播，但不做硬广告。

## 2. 视觉语言

| 项 | 规范 |
| --- | --- |
| 字体 | iOS 系统字体，中文默认苹方 |
| 主色 | 系统绿 `#34C759` |
| 辅助色 | 系统蓝、浅黄、淡粉、薄荷绿 |
| 背景 | `systemBackground`、`secondarySystemBackground` |
| 卡片圆角 | 16-24pt |
| Sheet 圆角 | 28-32pt |
| 动效 | spring、opacity、scale |
| 图标 | SF Symbols |

避免：

- 高饱和儿童玩具风。
- 强 3D 按钮。
- 大面积手写字体。
- 过度游戏化升级动画。
- 单一绿色铺满全局。

## 3. 首页规范

首页优先级：

1. 宝宝时间标签。
2. 成长树主视觉。
3. 已点亮数量和最近记录。
4. 记录新成长主按钮。
5. 历史和设置入口。

要求：

- 首页不展示大头像。
- 右上角仅保留设置图标。
- 时间标签居中，使用毛玻璃胶囊。
- 成长树占首屏核心视觉区。
- 底部“记录新成长”固定并使用高对比系统绿。
- Inspire v1.9 原型中主按钮使用高对比黑色，原生 V1 可采用黑色主按钮或系统绿主按钮；同一版本内必须保持一致，不能出现浅绿伪禁用态。

## 4. 表单规范

记录页和设置页采用系统分组表单。

- 日期：系统 DatePicker。
- 照片：PhotosPicker。
- 文本：TextField / TextEditor。
- 保存按钮：底部固定或导航栏明确操作。
- 禁用态：按钮置灰并不可点击。
- 模板页吸收原型的“搜索 + 卡片网格”结构；“岛屿地图”只做 V2 预告，不在 V1 实现。

## 5. 成长树视觉

V1 使用 SwiftUI 绘制的阶段树作为可替换资产。

正式插画接入原则：

- 保留阶段底图 + 装饰插槽结构。
- 插画不承载业务逻辑。
- 装饰数量超出后聚合，不无限堆叠。
- 删除记录时重新计算树状态，不出现枯萎或负反馈。

## 6. 分享卡规范

分享卡结构：

```text
出生第 X 天
节点标题
成长树局部/照片
情绪文案
来自「小芽成长」
```

排版要求：

- 浅色导出优先。
- 长标题允许缩放和换行。
- 长正文最多 4 行，避免溢出。
- 无照片时用成长树局部图兜底。

## 7. 无障碍

- 所有图标按钮必须有 VoiceOver label。
- 出生天数读作“宝宝出生第 X 天”。
- 颜色不能作为唯一状态表达。
- 支持系统动态字号，核心按钮不被挤压到不可点击。

## 8. 深色模式

V1 至少保证：

- 文字可读。
- 卡片层级清楚。
- 成长树不丢主要轮廓。
- 分享卡预览仍保持浅色优先的纪念感。
