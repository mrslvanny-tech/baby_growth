# 小芽成长 V1 测试用例

## 测试目标

确认核心使用旅程都能闭环返回，不出现白屏、卡死、无法退出或空状态崩溃；确认记录、历史、纪念卡、分享和保存图片这些关键动作可用。

## 自动化用例

### 核心成长记录闭环

- 入口：首次启动 App。
- 步骤：点击“开始记录成长”进入首页。
- 预期：出现“小芽成长”导航页，无崩溃。

### 新增成长记录闭环

- 入口：首页。
- 步骤：点击“记录新成长”，选择“第一次抬头很稳”，进入编辑页后点击“保存成长记录”。
- 预期：记录保存成功，自动弹出“纪念卡”页面，而不是白屏或空 sheet。

### 纪念卡退出闭环

- 入口：保存记录后自动弹出的“纪念卡”。
- 步骤：确认“分享给家人”和“保存图片”按钮存在，点击“稍后再说”。
- 预期：返回“小芽成长”首页，页面可继续操作。

### 历史记录闭环

- 入口：首页。
- 步骤：点击“查看历史记录”，找到刚保存的“第一次抬头很稳”。
- 预期：历史列表展示新记录，无空列表误判。

### 详情页纪念卡闭环

- 入口：历史记录页。
- 步骤：打开记录详情，点击“生成纪念卡”，再点击“完成”。
- 预期：纪念卡正常展示，点击完成后回到“成长详情”。

## 手动验收用例

### 分享给家人

- 步骤：在纪念卡页点击“分享给家人”。
- 预期：系统分享面板弹出，分享内容包含宝宝时间、记录标题、成长描述和“小芽成长”水印；取消分享后能回到纪念卡。

### 保存图片

- 步骤：在纪念卡页点击“保存图片”。
- 预期：首次保存时出现系统相册添加权限提示；允许后显示“已保存”，图片出现在系统相册。拒绝权限时显示明确失败提示，页面不会白屏或卡死。

### 取消编辑

- 步骤：进入“编辑记录”后点击“取消”。
- 预期：直接返回模板选择或上一层页面，不产生半条记录。

### 重复进入退出

- 步骤：连续执行“记录新成长 -> 取消”、“查看历史记录 -> 返回”、“生成纪念卡 -> 完成”各 3 次。
- 预期：导航层级稳定，无白屏、无重复 sheet、无返回按钮失效。

### iCloud 状态

- 步骤：进入设置页，查看“iCloud 同步”区域。
- 预期：展示同步状态说明；未登录或不可用时提供“打开系统设置”，不阻断本地记录。

### 删除成长记录

- 步骤：从历史记录进入成长详情，点击删除按钮。
- 预期：先出现确认弹窗；确认删除后返回历史列表，记录被移除，首页小树按剩余记录重新计算。
